# Resume Lab Template Library

This directory holds formatting templates used by the document compiler to format print-ready Word (`.docx`) and Markdown (`.md`) resumes and cover letters.

## Privacy Guardrail
Personal Word templates containing personal contact details or employment history (`*.docx`) are **strictly excluded from Git tracking** via `.gitignore` to maintain zero-cloud PII exposure.

## Included Standard Templates
- `Standard Executive Resume Template.md`: Universal markdown structure template with standard section hierarchy.
- To use your own private Word template, simply place your `.docx` file in this directory or upload it directly through the Resume Lab Studio interface (**Step 2: Template Card**).
